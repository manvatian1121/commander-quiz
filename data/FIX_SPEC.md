# 选项配平修正规范（三个 agent 共用）

我们要修两类**选项设计缺陷**。除这两类之外，**不要改动任何其它内容**（题干、其它选项、轴得分、id、next、goto 一律保持原样）。

## 修正一：缺「不在意」选项

### 判定标准
一道题同时满足下面三条，就是「缺不在意选项」的题：
1. 题干描述的是**别人/外部造成的、对你不利的处境**（被占便宜、被插队、被拖累、被误会、被抢功、东西坏了、计划被打乱……）
2. 所有选项都是**主动反应**：当场说、去处理、去追责、自己消化后离开、下次防着
3. 没有一个选项表达「**这事没往心里去 / 无所谓 / 随它去**」

### 处理
加一个「不在意」选项，例如：
- 「压根没往心里去，这事儿不值得占我的心思」
- 「算了，我不太计较这种小事」
- 「无所谓，反正也过去了」

**但必须做到：**
- 加完后选项数仍 ≤5。如果该题已有 5 个选项，**替换掉语义最重复的那一个**，不要变成 6 个
- 新选项必须有 **1~3 个轴得分**，权重只能用 1.0/1.5/2.0/2.5/3.0
- 「不在意」通常对应：`drain`（慢慢来、不计较）、`chaos`（随性）、`stompy`（直来直去不在乎细节）、`politics`（不想制造冲突）——**选哪个要看你新选项的具体措辞**，不要四道题都用同一组
- 新选项与同题其它选项的轴向量**余弦必须 < 0.85**
- **不要**给纯偏好题（「你喜欢什么样的 X」）加不在意选项——那类题没有「在意/不在意」之分

## 修正二：正负选项配平

### 判定标准
题干是**倾向性问句**（「你会……吗？」「你……吗？」「做完之后你会……吗？」），
并且选项可以按极性分成两组（会/不会、是/不是、有/没有、喜欢/不喜欢），
但两组数量**悬殊**（例如 4 个「会」对 1 个「不会」）。

### 处理
把比例调整到 **最多 3:2**（例如 4:1 → 3:2、5:0 → 3:2）。
两种做法任选：
- **加**少数派的一个选项（前提：加完不超过 5 个选项）
- **改**多数派里语义最重复的那一个，把它改写成少数派方向

改完仍然要满足：选项数 3~5、每个选项 1~3 个轴、权重合法、两两余弦 < 0.85。

4. 每题内两两选项余弦 < 0.85（列出最高的一对和数值）
