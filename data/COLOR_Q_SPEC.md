# 颜色题改写规范

## 背景：现有 4 道颜色题的三个问题

题库里只有 4 道题带颜色得分（`col` 字段），它们是全测试里**唯一**决定颜色倾向的题。
现有版本（s49 / s59 / s60 / s62）有三个毛病：

### 毛病一：一眼看穿

题干直接问颜色：

> 换个新手机，保护壳你会挑什么颜色？
> A. 明晃晃的**红** … B. 冷调的**蓝**灰 … C. 哑光**黑** … D. 磨砂**白** … E. 森林**绿**

用户反馈：「直球色组题太重复」。**颜色应该是被行为暗示出来的，不该是选择的对象。**

### 毛病二：四道题其实是同一道题

把四道题的选项按位置对齐，规律完全一样：

| 位置 | s49 | s59 | s60 | s62 |
|---|---|---|---|---|
| A | 红 | 红 | 红 | 红 |
| B | 蓝 · control 0.93 | 蓝 · control 0.93 | 蓝 · control 0.93 | 蓝 |
| C | 黑 · grave 2.17 | 黑 · stax 1.39 | 黑 · stax 1.39 | **白** |
| D | 白 · stax 1.39 | 白 · enchant 1.4 | 白 · enchant 1.4 | 黑 · stax 1.39 |
| E | 绿 · **ramp 1.69** | 绿 · **ramp 1.69** | 绿 · **ramp 1.69** | 绿 · **ramp 1.69** |

**四道题的 E 选项全是「绿 + ramp 1.69」，B 全是「蓝 + control 0.93」。**
所以一个喜欢法术力加速的人四题都选 E，四道题加起来提供的信息等于一道题。
**必须让四道题各自考察颜色的不同侧面，且轴分布不重复。**

### 毛病三：s62 的颜色映射有 bug

s62 的 C 选项是「**黑白**的纪实片」，却映射到 **W（白）**；而 D「高对比的**黑**」才是 B。
选了「黑白」却加白，用户会觉得莫名其妙。

## 改写要求

### 硬性约束

1. **四道题考察颜色的四个不同侧面**，建议方向（可调整）：
   - ① **怎么对待过去**（怀旧 / 记录 / 纪念）
   - ② **拿到新东西的第一反应**（求知 / 上手 / 收好）
   - ③ **面对规则和约束**（遵守 / 弄清 / 绕开 / 无视 / 顺应）
   - ④ **在群体里的位置**（组织者 / 观察者 / 独行者 / 跟随者 / 依附者）
2. **每道题 5 个选项，每选项恰好 1 个颜色**，`col` 值写 `2`（与现状一致）
3. **同一道题里，五个选项必须是五种不同颜色**（W/U/B/R/G 各一次）
4. **颜色不能出现在选项文本里**——不写「红」「蓝」「黑」「白」「绿」，也不写
   「橘红」「冷蓝」「墨绿」这类颜色词。颜色只能是行为的**副产品**
5. **四个题之间的轴分布不能重复**：同一道题里用过的轴组合，在另一道题里不要原样出现。
   尤其避免「每道题的某个选项都是 ramp」
6. 每选项 **1~3 个轴**，权重在 **0.5~3.0** 之间（现在是小数，因为做过轴平衡）
7. 同一题内任意两个选项的**轴向量余弦 < 0.85**（越接近 0 越好）

### 风格约束

- 题干用**口语化的一问**，像朋友聊天，不要书面语
- 选项要**具体、有画面**，不要抽象标签（写「先把说明书从头看一遍」，不写「偏理性」）
- 不要出现万智牌术语
- 五个选项的**吸引力要大致均衡**，不能有一个明显是「正确答案」
- 与题库里其它 140 道题**不要撞题**：先读 `data/bank4.json` 里已有的题，
  避免再写一道「怎么花钱」「怎么处理冲突」的重复题

## 交付

改 `<repo>\data\bank4.json` 里这四道题（`id` 保持 s49 / s59 / s60 / s62 不变，
位置和 `next` 不要动），只改 `q` 与每个选项的 `t`、`s`、`col`。

改完写自检脚本确认：
1. 四道题 id 与顺序未变，`next` 未变
2. 每题恰好 5 选项，每选项恰好 1 个颜色，且同题内五色齐全
3. **选项文本里不含颜色词**（扫「红蓝黑白绿灰紫橙黄粉青金银」）
4. 每选项 1~3 轴、权重合法
5. 同题内两两余弦 < 0.85，并报出最高的一对
6. **跨题轴复用检查**：列出四道题各自用到的主轴，确认没有「同一位置总是同一个轴」

最后回报：改动清单（题号 / 新题干 / 五个选项及其颜色与轴 / 为什么这样设计），
自检 6 项结果，以及你认为「这样写颜色信号够不够清楚」的自我评估。
