# 全库校对规范

我们在做一次**文字校对**。目标不是改玩法、不是改轴得分，而是**找出读起来不对劲的地方**。

## 背景：已经发现的一个真实案例

题 s18「公司要你三个月后搬去另一个城市。你从哪一步开始？」的选项 B 原本写的是：

> ❌ 把全家的时间表排出来，谁哪天干什么都写清楚

问题：题目问的是**搬家**，其它四个选项都在讲搬家（找熟人接应、先住酒店、打包、挑家具），
只有 B 说的是「排全家人的作息表」，跟情境对不上。看它的轴得分 `{stax 2.5, ramp 1.5, control 1.0}`
（定流程 / 提前准备 / 计划），本意显然是「把搬家流程排成时间表」——**写的时候掉了词**。

改成：

> ✅ 先把整套流程排成时间表，谁哪天干什么都写清楚

**这类问题就是我们这一轮要找的。** 它不会被「选项两两余弦」检查抓到，也不会被结构校验抓到，
只有人读才能发现。

## 要找的六类问题

| # | 类型 | 说明 | 例子 |
|---|---|---|---|
| 1 | **掉词 / 多词 / 搭配不当** | 句子读起来别扭、缺成分、动宾搭不上 | 上面的 s18 |
| 2 | **选项没回答题干** | 题干问 X，某个选项实际答的是 Y | 题干问「怎么开始」，选项答的是「结果怎样」 |
| 3 | **情境不对应** | 题干设了一个场景，某个选项跟这个场景无关 | 题干在讲职场，选项在讲家庭 |
| 4 | **错别字 / 的得地 / 在再 / 做作** | 明显的字词错误 | 「必需」写成「必须」这种 |
| 5 | **人称或语气突变** | 同一题里选项突然换人称（你 / 我 / 我们）或语气 | A 用「你」，B 突然用「我」 |
| 6 | **重复啰嗦** | 同一句话里说了两遍同一件事 | 「先提前早一点准备」 |

## 严格限制（重要）

- **不要改轴得分**（除非文字改了之后原轴得分明显对不上了，那种情况要单独说明理由）
- **不要改 id / next / goto / kind / multi / sec**
- **不要改选项数量**
- **不要重写读起来没问题的句子** —— 宁可少改。只改确实有问题的
- **不要改变口语化的风格** —— 这套题本来就是聊天口吻，「我觉得」「压根」这类是刻意的
- 改完后**逐条列出**：题号 / 类型 / 原文 / 改后 / 为什么

## 交付与自检

改完跑校验，逐项确认：
1. id 集合与顺序没变
2. next / goto 没变
3. 每题选项数没变
4. 每个选项的轴得分键没变（除非你明确标注了理由）
5. 题内选项文本仍然两两不同

报告里给出：**改了几处 / 每处的题号与理由 / 你判断「看着可疑但其实没问题」而放过的若干处及原因**。

最后一条很重要——我要知道你放过了什么，那代表你的判断边界。
