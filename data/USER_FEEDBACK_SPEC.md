# 九道题的修改规范（用户实测反馈）

用户实际玩了一遍，逐题提了 9 条意见。逐条照做，**不要顺手改别的题**。

## 硬性约束（每条都适用）

- 每题选项数 **3~6** 个
- 每选项 **1~3 个玩法轴**，权重 **0.5~3.0**
- 同题内任意两选项的**轴向量余弦 < 0.85**（越接近 0 越好）
- 选项文本**不能出现万智牌术语**
- 五个选项的**吸引力要均衡**，不能有一个明显是「正确答案」
- 语气保持口语化，像朋友聊天

## 逐条任务

### 图1 · `s04`「周末一整天没人约你，你多半会怎么过？」
**反馈**：缺一个「呆在家里打游戏或者躺着」的选项。

现有 5 个选项全是「出门」或「在家做事」，没有「纯躺 / 打游戏」这个最常见的选择。
**加一个**（5 → 6 个），落在「低投入、自己待着、不折腾」的感觉上。

### 图2 · `h1c3`「有一种玩法你熟得不能再熟，现在有人叫你换一种完全不同的，你？」
**反馈**：缺一个「不改变」的选项。

现有 A（换）、B（嫌麻烦不折腾）、C（改成自己熟的）、D（两个一起玩）——
B 是「嫌麻烦」，不是「就是不想换」。**加一个明确的「不换」**（4 → 5 个）。

### 图3 · `s19`「你要买一台大件…下单前你在干嘛？」
**反馈**：B「干脆两台都买回来用一周，留顺手的那台」有些怪。

确实不现实（大件退货成本高、也不合常理）。**改写 B**，让它成为一个真实的购买策略，
例如「先定一条最不能让步的硬指标，其余看眼缘」这类。

### 图4 · `s24`「…最先冒出来的是哪个念头？」——**枢纽题，只能改不能加**
**反馈**：B 和 C 有些类似。

现有：A 信息够不够 / B 最坏能坏到哪，我兜不兜得住 / C 万一走错了，我还能不能回来。
B 和 C 都在问「下行风险」，确实重复。

⚠️ **这题是枢纽题**：三个选项各自 `goto` 一条分支（h2a1 / h2b1 / h2c1），
**绝对不能增删选项**，否则分支会断。只能**改写 B 或 C 的措辞**让两者分开。
建议让 B 落在「承受能力」（资源够不够兜），C 落在「可逆性」（能不能回头），
或者把其中一个换成完全不同的角度（如「我到底想要什么结果」）。

### 图5 · `s36`「合租室友连续一周吃完饭把碗堆在水池。你——」
**反馈**：可以加或换一个「直接要求舍友清洗其堆积的碗」。

现有 A 是「排值日表」（制度化），D 是「划清界限」，E 是「当面阴阳」，
**缺一个最直白的「你，把碗洗了」**。加一个（5 → 6 个）或替换掉语义最弱的那个。

### 图6 · `s45`「有人当着别人的面开了你一个不好笑的玩笑。第一反应——」
**反馈**：加一个「阴阳怪气的反击回去」。

现有 A 是正面硬刚、C 是心里划清界限、D 是自嘲救场，
**缺「笑着把话扎回去」这一档**。加一个（4 → 5 个）。

### 图7 · `s50`「周末晚上打开电视，你会点开哪一类片子？」
**反馈**：现代人更多是刷视频；可以加一个动画类。

两个动作：① 题干改成覆盖「看片 / 刷视频」两种；② 加一个**动画 / 番剧**类的选项。
注意加完要保证和现有选项的区分度。

### 图8 · `s51`「耳机里放的东西，最常是哪一种？」
**反馈**：可以加有声小说或知识类视频的音频。

现有全是音乐。**加一个「听内容而不是听音乐」的选项**（有声书 / 播客 / 知识类）。

### 图9 · `c05`「玩游戏时有个套路特别有效，但会让对手很难受。你会用吗？」——**约束题**
**反馈**：B「看人下菜。跟熟人就随便玩，跟不熟的用」有语句问题。

「跟不熟的用」缺宾语，且「看人下菜」是贬义成语、放这里语气不对。
**把这个选项的句子改通顺**，语义保持「看对象决定用不用」。

⚠️ 这题是**约束题**，选项带 `cval` 字段（难度/预算/咸度容忍度），
**`cval` 的值不要动**，只改文本；若要动轴得分，说明理由。

## 交付与自检

改 `data/bank1.json`（s04、s19、s24、s36、s45、s50、s51）与
`data/bankC.json`（c05）、`data/bank1.json` 里的 `h1c3`。
id、next、goto、kind、cval、题目顺序**一律不动**。

自检脚本必须验证：
1. 改动只落在这 9 道题里，其它题零改动（逐字段 diff）
2. id / next / goto / kind / cval 全部未变（**枢纽题 s24 的 goto 尤其要确认**）
3. 每题选项数 3~6，每选项 1~3 轴、权重在 0.5~3.0
4. 同题内两两余弦 < 0.85，报出每题最高的一对
5. 选项文本无万智牌术语、同题内不重复
6. 改 `s24` 前后，三条分支 h2a1/h2b1/h2c1 仍然可达

最后回报：逐题改动清单（题号 / 旧文本 / 新文本 / 新轴 / 为什么这样改）、
自检 6 项结果、以及你判断「这条反馈我这样处理对不对」的说明。
